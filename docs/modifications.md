# 자체 변경 이력

## 초기 기준: 2026.11.13.1

현재 설치된 파일을 보존하고, 과거 작업 기록으로 확인되는 주요 수정을 정리했다. 이 목록은 모든 파일 차이의 완전한 분석을 의미하지 않는다. 원본 미확인 항목은 원본을 확보한 뒤 비교해야 한다.

각 기능 변경은 목적과 제거 조건을 주석으로 설명한다. 기존 소스의 동작을 불필요하게 재작성하지 않는다.

## 업데이트 후보: 2026.11.14.1

- 공식 CurseForge 포에버 지원 파일 16종을 점검하고, 기능 삭제가 있는 ForeverLootSparkles를 제외한 15종을 최신 원본에 병합했다.
- Questie 12.9.0 / QuestieDB 1.1.1, Attune 16001-41, 던전 도감 2.0.5, ForeverAuras 1.4.0 및 부속 모듈로 갱신했다.
- BlizzMove 3.8.8, Clique 5.1.5, idTip 12.1.10, Myslot 6.3.0, Prat 3.9.117, WIM 3.19.6, TomTom 4.4.1, Leatrix Maps 1.60.31 / Plus 1.60.30 / Sounds 1.60.30으로 갱신했다.
- 설치된 BetterFishing 66 한국어 UI·장비 전환 미니 버튼(복귀 기록 보존 수정 포함), 한국어가 내장된 ForeverThreat 1.7.4를 등록했다.
- 정확한 이전 원본과 설치 수정본, 새 원본을 3방향 비교했다. Attune의 변경된 한국어 값만 새 사전에 이식했고, 던전 도감의 최신 전용 폰트·지도/퀘스트 로직과 한국어 연결을 함께 유지했다.
- idTip의 새 한 줄 표시 옵션을 번역하고 최신 compact 동작/반환값을 보존했다.
- WIM의 Sources/EditMode.lua는 사용자에게 적용했던 독립 편집기 구현을 유지했다. 최신 원본의 관리자 패널 구현과 혼합하지 않았으며, 다른 WIM 파일/번역은 최신 원본에 병합했다.
- ForeverLootSparkles는 2.0.0에서 약초·광맥·시체 반짝임이 삭제되어, 사용자의 채집 기능을 보존하는 1.3.1로 유지한다. 자동 업그레이드 대상에서 보류했다.
- Questie에 동봉된 별도 QuestieTrace 데이터 수집 모듈은 신규 설치/등록하지 않았다.
- AI 클라이언트/PC 브리지는 이번 제3자 애드온 업데이트 범위에서 변경하지 않았다. 실제 수신 내용·로그·인증 정보·WTF/SavedVariables를 복사하지 않았다.
- 원본 파일 ID/아카이브 SHA-256은 lock에 기록했다. 게임 내 동작은 아직 확인하지 않았으며, 이 커밋은 배포 태그가 아닌 PR 검토 후보이다.

## Attune 제외: 2026.11.14.2

- 사용자 요청에 따라 addons/Attune과 upstream/Attune, 배포 lock의 Attune 항목을 제거했다.
- 로컬 설치 폴더는 AddOns 밖의 백업 폴더로 이동했으며, WTF/SavedVariables의 진행 설정은 원본을 유지하고 별도 백업했다.
- 다른 팀원의 기존 Attune은 개인 애드온 보존 정책상 sync.py가 자동으로 삭제하지 않는다. 제거하려면 본인 AddOns/Attune 폴더만 백업 후 삭제한다.
- 다른 애드온의 소스와 동기화 동작은 변경하지 않았다.

- Questie 12.12.0, QuestieDB 1.1.4, ForeverAuras 1.4.6과 부속 모듈을 포에버 공식 배포본으로 갱신했다.
- 이전 원본과 게임 설치본을 대조해 기존 한국어 및 기능 수정 사항을 새 원본에 병합했다.
- Lua 5.1 문법과 배포 파일 해시를 확인했다. 게임 내 동작은 아직 확인하지 않았다.
- 던전 도감은 기존 수정과 충돌이 남아 이번 후보에 포함하지 않았다.
- Auctionator 351, Leatrix Plus 1.60.37, WIM 3.19.8도 공식 원본을 기준으로 기존 수정 사항을 병합했다. 게임 내 검증은 아직 하지 않았다.
- Leatrix Sounds 1.60.31 및 Myslot 6.3.1에 기존 수정 사항을 병합했다.
