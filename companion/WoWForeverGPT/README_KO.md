# 와우 AI

와우 포에버 채팅창에서 `/ai 질문`을 입력하면 전용 창이 열리고 AI 답변을 한국어로 보여줍니다. 창 안에서 Enter로 후속 질문을 보낼 수 있습니다. 답변은 포에버 기준으로 짧게 작성하도록 설정했습니다. 제품 이름은 연결 모델과 구분하며 현재 연결은 ChatGPT 로그인과 Codex CLI를 사용합니다.

## Windows 설치

1. [Node.js](https://nodejs.org/) 22.2 이상이 필요합니다. Codex 데스크톱 앱에 이미 로그인했다면 포함된 CLI를 자동으로 찾아 사용합니다. Codex가 없는 PC에서는 PowerShell에서 아래 두 줄을 실행하고 ChatGPT 계정으로 로그인하세요.

   ```powershell
   npm install -g @openai/codex
   codex login
   ```
2. 와우를 완전히 종료하고 ZIP을 원하는 폴더에 푸세요. 그 폴더에서 **Install.cmd**를 실행하세요.
3. 경로를 자동으로 찾지 못하면, 압축을 푼 폴더에서 PowerShell을 열고 아래처럼 실제 게임 실행 파일이 있는 폴더를 지정하세요.

   ```powershell
   node setup.js --wow "C:\Games\World of Warcraft\_forever_"
   ```

4. 와우를 다시 실행하고 캐릭터 선택 화면의 애드온 목록에서 **와우 AI**와 **와우 AI 응답 슬롯**들을 활성화하세요. 게임 화면 모드는 **창 모드 또는 전체 화면(창 모드)**을 사용하세요.
5. **GPT-Auto-On.cmd**를 한 번 실행하면 자동 연동을 켭니다. 이후 윈도우 로그인 때 감시자가 시작되고, 와우 포에버가 실행될 때 와우 AI 연결 프로그램을 켭니다. 시작할 때 기존 ChatGPT 로그인 상태를 확인합니다.
6. 와우 채팅창에 `/ai 포에버에서 힐러 주술사는 레벨업 중 무슨 스탯을 챙겨요?`를 입력해 보세요.

설치 폴더는 원본 `WoWAI`와 구분됩니다. 원본 AI Chat이 설치되어 있다면 게임의 애드온 목록에서 원본을 비활성화해 `/ai` 명령 충돌을 피하세요. 연결 프로그램은 백그라운드에서 실행됩니다. 자동 연동이 켜져 있으면 와우 포에버 실행 시 연결하고, 마지막 포에버 창이 종료되면 연결 프로그램과 그 하위 프로세스도 종료합니다. 감지 간격은 약 3초이며 리테일과 다른 클래식 실행은 무시합니다. 대기 중인 감시자는 GPT를 호출하거나 화면을 수집하지 않습니다. 중복 실행을 막으며 진단 로그는 `bridge/auto-watch.log`, `bridge/console.log`, `bridge/console-error.log`에 남습니다.

자동 연동을 해제하려면 `GPT-Auto-Off.cmd`를 실행하세요. 이후에는 `GPT-Start.cmd`와 `GPT-Stop.cmd`로 수동 제어할 수 있습니다. 자동 연동이 켜진 채 게임이 실행 중이면 연결 프로그램만 수동 종료해도 다시 시작합니다. 윈도우 현재 사용자 시작 항목과 예약 작업 `WoWForeverGPT.AutoWatch`를 사용하며, 중복 감시는 차단합니다.

업데이트할 때는 와우를 종료하고 새 ZIP을 기존 와우 AI 폴더에 덮어 푼 뒤 **Install.cmd**를 다시 실행하세요. 기존 대화 기록과 개별 연결 설정은 유지됩니다.

## 사용

질문창 하나로 사용합니다. 포에버 전용 퀘스트 안내·아이템 비교·BIS·단축키 답변 지침을 시스템 프롬프트에 보완했습니다.
질문할 때 현재 캐릭터의 이름·직업·레벨·종족·진영·지역·특성·기본 능력치·장비 이름/ID를 함께 전달합니다.
질문이 길면 기본 정보부터 담고 일부 세부 정보는 생략할 수 있습니다. 전체 아이템 옵션이나 실제 키 설정처럼 첨부하지 않은 정보만 필요할 때 물어보게 했습니다.
정보는 질문 전송 시 읽으며 별도 창이나 상시 스캔은 추가하지 않았습니다. `/wow-ai context off`로 끄고 `on`으로 다시 켤 수 있습니다.
캐릭터 정보의 반복 문구는 SC1 고정 사전의 짧은 코드로 전송하고 PC에서 원문으로 완전히 복원합니다. 기존 정보·잘림 기준·AI 입력은 유지하면서 화면 신호 전송량을 줄입니다. AI 입력 토큰을 줄이는 방식은 아닙니다.
아이템이나 퀘스트를 Shift+클릭으로 첨부하는 기존 기능은 유지합니다.

- 기본 창은 460×310이며 왼쪽 위 **목록/접기** 버튼으로 대화 목록을 여닫습니다. 처음에는 목록이 접혀 있고, 사용자가 바꾼 크기와 목록 상태는 저장됩니다. 최소 크기는 380×260입니다.
- 답변의 **중요 키워드**는 크림색, `명령어`는 연한 청록색, 주의 문구는 살구색으로 표시합니다. 기존 답변의 따옴표 속 표현도 강조합니다. 답변을 클릭하면 서식 기호 없는 텍스트를 복사할 수 있습니다.
- `/ai`로 질문 창을 열고 닫습니다. 창 안에서 아이템이나 퀘스트를 Shift+클릭해 질문에 첨부할 수 있습니다.
- **대화 비우기**는 현재 창을 비우고 다음 질문에서 GPT 문맥을 초기화합니다. 기록을 브리지에서도 지우려면 대화 목록의 삭제 버튼을 사용하세요.
- 질문창 아래 **추론: 낮음** 버튼을 누르면 **낮음 → 보통 → 높음** 순서로 바뀝니다. 선택값은 저장되며 다음 질문부터 적용됩니다.
- 연결은 로그인한 계정의 Codex 구독 한도를 사용합니다. 질문과 직접 첨부한 툴팁, 최근 성공한 질문·답변 최대 5쌍을 Codex에 전달합니다. 와우 전용 대화 기록은 `bridge/transcripts.json`에 보관됩니다.
- **연결**은 실행 중인 PC 연결 프로그램에 응답을 요청합니다. 신호를 받지 못했다는 안내만으로 프로그램이 꺼진 것은 아닙니다. Windows 수신기는 신호 칸의 소수점 픽셀 간격을 자동 보정하며 전체 체크섬 검증을 통과한 패킷만 받습니다. 응답 슬롯을 다 쓰면 **UI 새로고침**으로 다시 사용할 수 있습니다.
- 화면 위 색상 신호 줄은 요청을 전송할 때만 잠시 나타납니다. 응답 슬롯의 접수증으로 수신을 확인하면 답변 생성 중이어도 신호 줄을 감춥니다. 소리 파일이 캐시되어도 삭제 요청의 접수증을 별도로 확인합니다.

## Claude로 답변받기

OpenAI 모델에서 **Sol 6.2**가 기본이며 **Astra 6.2**도 선택할 수 있습니다. 이전에 선택한 Sol 6.1 또는 Terra 6.1은 버전 업데이트 시 한 번 Sol 6.2로 바뀝니다. 이전 모델은 메뉴에서 다시 선택할 수 있습니다.

GPT 외에 Claude로도 답변받을 수 있습니다. AI는 대화마다 따로 고릅니다.

- 창 오른쪽 위의 **모델 버튼**(예: `Sol 6.2`, `Sonnet 5.5`)을 누르면 회사별(OpenAI·Anthropic) 모델 목록이 열립니다. 모델을 고르면 이 대화의 AI가 그 회사로 바뀌고, 고른 모델은 그 회사의 선택으로 저장되어 다음 질문부터 쓰입니다. 답변 이름표와 알림에는 실제로 답한 모델이 `Opus 5.5`처럼 모델 이름만 짧게 표시됩니다.
- 채팅 명령으로 바꿀 수도 있습니다: `/wow-ai agent claude`, `/wow-ai agent gpt`.
- PC에 Claude 데스크톱 앱이나 Claude Code가 설치되어 있고 claude.ai 계정으로 로그인되어 있어야 합니다. 브리지가 앱에 포함된 CLI를 자동으로 찾습니다. 찾지 못하면 환경 변수 `WOW_CLAUDE_BIN`에 `claude.exe` 경로를 지정하세요.
- 사용량은 로그인한 Claude 구독 한도에서 차감됩니다. `ANTHROPIC_API_KEY`가 있어도 API 과금으로 넘어가지 않도록 브리지가 이 값을 지우고 실행합니다.
- Claude에는 웹 검색과 페이지 열기 도구만 허용합니다. 사용자 CLAUDE.md, 플러그인, MCP는 불러오지 않습니다(`--safe-mode`).
- 메뉴에 나오는 모델 목록과 회사별 기본 모델은 `bridge/config.json`의 `models`에서 바꿀 수 있습니다. 게임이 보낸 모델이 이 목록에 없으면 그 회사의 기본 모델로 답합니다. `defaultAgent`는 AI를 따로 고르지 않은 대화의 기본값(`gpt` 또는 `claude`)입니다. 설정 파일을 바꾼 뒤에는 연결 프로그램을 다시 켜야 적용됩니다(`GPT-Stop.cmd` 실행 후 자동 연동이 다시 켬).
